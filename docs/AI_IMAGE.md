# 이미지 AI 보완 (REQ-02-006)

정의서의 '이미지·도식 AI 생성 및 수정 보완' 가운데 표기, 현황, 유의 안내와 화질 보정의 연결을 맡습니다. 화면은 메뉴 **이미지 › 이미지 AI 보완**(`/ai-image`)입니다.

| 정의서 항목 | 상태 | 어디 |
|---|---|---|
| ① AI 생성 | 없음 | 이미지 생성 모델과 외부 전송 승인이 먼저 필요합니다 |
| ② AI 수정 보완 | 화질 보정만 | `ncs_upscale`(업스케일링 화면). 보정한 그림을 이미지 저작권 DB에 AI 활용 정보와 함께 올립니다. 내용 수정은 없습니다 |
| ③ 표기 문구 자동 삽입 | 구현 | `ncs_core/figures.py`(줄 쓰기), `ncs_aiimage/marking.py`(원고에 넣기) |
| ④ 생성형 AI 결과물 현황 자동 작성 | 구현(xlsx) | `ncs_aiimage/results.py` |
| ⑤ 프롬프트 유의 안내 | 구현 | `ncs_aiimage/notice.py`, 화면에서 확인해야 내려받기가 열립니다 |

## 표기 (③)

그림 한 개의 표기는 세 줄입니다(F14 집필 양식, F08 AI 도구 사용 표기 예).

```
출처: 집필진 제작(2026)                       ← 원고에 있던 줄 그대로
ChatGPT를 활용하여 수정 보완함. 2026. 7. 20.  ← 넣는 줄
[그림 1-1] 생산 설비 주요 구성 요소           ← 원고에 있던 줄 그대로
```

- 넣는 줄은 `ncs_core.figures.ai_line(도구, 방식, 일자)`가 만듭니다. 방식은 `generated`(생성함)와 `modified`(수정 보완함) 둘입니다. 조사 '을/를'은 도구 이름의 끝소리로 정합니다.
- 넣는 자리는 캡션 문단 바로 앞입니다. 새 문단의 모양은 출처 줄을 따르고, 출처 줄이 없으면 캡션을 따릅니다.
- **출처 줄은 넣지 않습니다.** 없는 출처를 지어낼 수 없어서입니다. 화면이 '출처 줄 없음'으로 알려 줍니다.
- 이미 AI 활용 줄이 있는 그림에는 넣지 않습니다.
- hwpx 원고만 됩니다. 올린 원고는 바꾸지 않고 사본을 돌려줍니다. 넣은 줄 말고는 문단 글이 같고, 그림 파일과 다른 항목은 바이트 그대로입니다.
- 도구 이름에는 쉼표를 쓸 수 없고, 마침표는 판 번호의 숫자 사이(`ChatGPT 6.0`)에만 쓸 수 있습니다. 읽는 쪽(`parse_ai_mark`)도 이번에 숫자 사이의 마침표를 이름의 일부로 읽게 고쳤습니다(전에는 `ChatGPT 6.0을 활용하여`에서 도구를 `0`으로 읽었습니다).
- 읽은 문서의 구역은 파일의 구역과 다를 수 있습니다(`normalize_sections`가 앞부분과 본문으로 다시 나눕니다). 넣을 자리는 문서 전체에서 몇 번째 문단인지로 찾고, 파일의 문단 수가 읽은 것과 다르면 아무것도 넣지 않습니다.

검수 쪽에서는 필요 지식 ⑧이 같은 읽기로 AI 활용 줄의 꼴과 순서를 판정합니다(`docs/CONSISTENCY_REVIEW.md` 5.21).

## 현황 (④)

원고에서 AI 활용 줄이 붙은 그림을 모아 서약서 붙임 양식의 칸으로 만듭니다: `순번 | 결과물 명 | 학습모듈 해당 쪽수 | 활용 AI | 비고`.

- 결과물 명은 `그림 1-1 그림명`, 비고에는 방식과 일자를 적습니다.
- 쪽수는 출력본 PDF를 함께 올렸을 때만 `p.12`로 적습니다. 같은 그림 번호가 여러 쪽에 있으면 모두 적고 비고에 알립니다.
- 파일은 xlsx입니다. 한글 양식(hwpx)으로는 만들지 않습니다. 서약서 붙임에 옮겨 적어야 합니다.

## 화질 보정과의 연결 (②)

- 업스케일링 화면의 제안본 내려받기에 **제안본에 AI 활용 표기 넣기**가 있습니다(기본 켜짐). 보정한 그림의 캡션 위에 `waifu2x를 활용하여 수정 보완함. 오늘 날짜` 줄을 넣습니다. 도구 이름은 모델에 따라 `waifu2x` 또는 `Real-ESRGAN`입니다.
- **이미지 저작권 DB에 올리기**(에디터와 직능연, 데이터베이스가 있을 때): 원본과 업스케일본, 수록 위치, AI 활용 정보(활용 유형 3 '기존 이미지 보정', 수정 보완, 도구, 일자, 원본 출처 = 원고의 출처 줄)를 이미지 레코드로 적재합니다. 기관이 확정한 그림의 권리 정보는 바꾸지 않습니다. 분류 체계와 재사용 범위는 정하지 않습니다.
- 캡션을 찾지 못한 그림은 표기도 DB 등록도 건너뛰고 그 수를 알려 줍니다.

## API

| 경로 | 내용 |
|---|---|
| `GET /api/ai-image/notice` | 유의 안내(근거와 항목) |
| `POST /api/ai-image/figures` | `manuscript`(hwp, hwpx) + `print_copy`(PDF, 선택) → 그림 목록, 이미 있는 AI 표기, 쪽 |
| `POST /api/ai-image/preview` | + `marks` → 그림마다 표기 세 줄과 현황 줄 |
| `POST /api/ai-image/marked` | `manuscript`(hwpx) + `marks` → 표기를 넣은 원고 사본. 요약은 `X-Ai-Summary` |
| `POST /api/ai-image/results` | `manuscript` + `print_copy` + `marks` → 현황 xlsx |
| `POST /api/ai-image/source` | `manuscript`(hwpx) + `key` + `credit` → 출처 줄이 없는 그림에 출처 줄을 넣은 사본(이미지 추천이 씀, `docs/RECOMMEND.md`) |
| `POST /api/uploads/{token}/proposal` | `ai_mark=true`, `ai_date`(선택)를 주면 제안본에 표기를 함께 넣음 |
| `POST /api/uploads/{token}/pictures/register` | 보정한 그림을 이미지 저작권 DB에 올림 |

`marks`: `[{"key": 그림 목록의 key, "tool": "ChatGPT", "mode": "generated" | "modified", "date": "YYYY-MM-DD"}]`. 올린 파일은 읽는 동안만 임시 폴더에 두고 지웁니다. 데이터베이스에 남기는 것은 DB 등록을 눌렀을 때의 이미지 레코드뿐입니다.

## 검증 (2026-11-23)

| 정의서 기준 | 결과 | 표본 |
|---|---|---|
| 표기 문구 삽입 100% | 129개 중 129개 삽입 | `samples/`의 실제 원고 5권(51, 17, 17, 17, 27그림), 표기가 없는 그림 전부에 넣음 |
| 생성함/수정 보완함 구분 오차율 0.5% 이내 | 틀림 0 / 129, 줄 단위로는 0 / 150 | 위 원고에서 번갈아 넣고 다시 읽음. 줄 단위는 도구 15 × 방식 2 × 날짜 5 |
| 결과물 현황표와 원고 표기 일치 100% | 현황 쪽 지적 0건 | 합성 원고 1권: 표기를 넣은 원고와 그 현황으로 권리 증빙 점검(`ncs_rights`)을 돌림 |

한계

- 넣은 원고를 **한글 프로그램에서 열어 보지는 못했습니다.** 읽기(이 저장소의 hwpx 읽기)로만 확인했습니다. 글자 모양과 쪽 넘김은 한글에서 확인해야 합니다.
- 삽입과 구분의 표본은 넣은 것을 같은 저장소의 읽기로 다시 읽은 것입니다. 사람이 적은 표기를 읽는 정확도와는 다른 값입니다.
- 현황 일치는 합성 원고 1권입니다. 쪽수는 실제 출력본으로 재지 않았습니다.
- 유용성(Likert)과 유사성 Recall@k는 생성 기능이 없어 잴 것이 없습니다.

## 원본 이용 조건 확인 (REQ-02-006 ⑥)

출처 줄에 적힌 공공누리 유형을 읽어(`ncs_core.source_line.kogl_terms`) 조건에 맞게 막거나 알립니다. 유형이 적혀 있지 않은 그림은 판단하지 않습니다(추측하지 않음).

| 원본 | 업스케일(화질 보정) | AI 활용 표기 넣기 | 결과물 현황 |
|---|---|---|---|
| 제3·4유형(변경금지) | 목록에 '업스케일 제외'로 보이고 실행을 거절 | 고를 수 없고, 요청에 섞여 오면 빼고 '변경금지 원본 제외'로 알림 | 이미 AI 표기가 있으면 비고에 '변경금지 원본 — 확인 필요' |
| 제2·4유형(상업적 이용금지) | 조건을 알림 | 넣음 | 비고에 '원본 공공누리 제N유형: 비상업적 이용만 가능' |
| 그 밖의 유형 | 그대로 | 넣음 | 비고에 '원본 공공누리 제N유형' |

검증 기준 '변경금지(제3·4유형) 원본의 수정 보완 0건'은 이 도구를 거친 경로에만 해당합니다. 이용허락 범위에 변경이 허용되지 않은 그 밖의 자산(공공누리가 아닌 것)은 출처 줄만으로 알 수 없어 다루지 않습니다 — 이미지 저작권 DB의 권리 정보와 연결해야 합니다.
