# 05 기타 ③ 상호·상품명·프로그램명·인물 (task `misc3_names`)

보내는 것: 본문 문단.
**코드가 먼저 뺄 것**: '출처:' 줄(F14가 프로그램명을 쓰게 함), 참고 자료 구역(서지), 메모, 수행 블록의 재료·기기 줄(수행 ② `perform2_brands`가 따로 봄).
엔진 사전(`ncs_misc/rules/brand_names.py`)이 이미 잡은 문단도 **빼지 않고** 보낸다 — 엔진 결과는 LLM에 넣지 않고(설계메모 7장), 나중에 문단 번호 `n`으로 합친다.
그림 속 로고·인물은 이 task가 아님(비전 모델 별도).

## [체크 항목]

```
[체크 항목] 기타 ③
본문 텍스트에 특정 상호, 상품명, 제품 모델명, 모델 번호, 특정 프로그램명, 인물 등이 노출되지는 않았는가?
- 삭제하거나 일반 명칭으로 바꿔야 함. 예: 엑셀, 아래아 한글 → 스프레드시트 프로그램
```

## [판단 기준]

```
[판단 기준]
검수 대상 문단에서 아래에 해당하는 이름을 찾는다. 한 문단에 여러 개면 이름마다 따로 지적한다.
- 지적함:
  · 상호: 특정 회사·가게·브랜드 이름 (예: ○○전자, ○○마트)
  · 상품명: 특정 제품·서비스 이름, 제품 모델명, 모델 번호 (예: ○○ 3000, AB-123)
  · 프로그램명: 특정 소프트웨어·앱·웹 서비스 이름 (예: 엑셀, 파워포인트, 포토샵, 카카오톡)
  · 인물: 실존 인물의 실명 (예: 특정 업체 대표, 연예인, 강사)
- 지적하지 않음:
  · 일반 명칭: 스프레드시트 프로그램, 문서 편집기, 메신저, 냉장고 등
  · 이 분야에서 누구나 쓰는 보통 명칭·약어: {분야_공용명칭}
  · 표준·법령·공공기관 이름: KS, ISO 9001, 산업안전보건법, 고용노동부, 한국산업인력공단 등
  · 학설·이론·법칙에 붙은 학자 이름: 매슬로의 욕구 단계 이론, 파레토 법칙 등
  · 프로그래밍 언어·파일 형식·기술 표준 이름: Python, SQL, PDF, HTML, USB 등
  · 상품명이 일반 명사가 된 말(예: 포스트잇, 호치키스)은 일반 명칭이 따로 널리 쓰이면 지적하고(→ 접착식 메모지, 스테이플러), 아니면 지적하지 않는다.
- 일반 낱말과 겹치는 이름(한글, 워드, 윈도우, 오피스, 줌)은 문맥상 제품을 가리킬 때만 지적한다.
- 다음도 지적하지 않는다.
  · 개념·방법론·문서 이름의 영문 약어: SWOT, KPI, SDLC, RTM, NDA, OSS, API 등
  · 예시용 가상 이름: ○○기업, A사, 홍길동처럼 실제 대상을 가리키지 않는 이름
  · 오픈소스·표준 기술의 이름이 특정 회사 제품이 아니라 기술 방식을 가리킬 때(예: 오픈소스 라이선스, 클라우드 컴퓨팅)
- "○○ 등"처럼 예를 들려고 회사·서비스 이름을 쓴 것도 지적한다(예: "외부 상용 AI 모델(OpenAI 등)" → 상호).
```

`{문제_종류}` = `상호` | `상품명` | `프로그램명` | `인물`

"인용"은 이름 부분만(예: "엑셀"), "수정 문장"은 그 이름을 일반 명칭으로 바꾼 문단 전체.

## [찾을 곳] — 슬라이스 ①·②(원고를 통째로·고정 길이로 보낼 때)만 붙임. ③은 코드가 이미 그 부분만 잘라 보냄

```
[찾을 곳]
본문 전체(필요 지식, 수행 내용, 평가 등)의 문단이 검수 대상이다.
다음은 검수 대상이 아니다: '출처:'로 시작하는 줄, '참고 자료' 부분(서지), 수행 내용의 '재료·자료'와 '기기(장비·공구)' 줄,
학습모듈 활용 안내·차례·개요, 집필진·검토진 명단과 판권 면.
```

## [예시] — 기본 예시(직접 만든 문장)

```
[예시]
지적함
- "엑셀의 피벗 테이블 기능으로 월별 매출을 요약한다."
  → 문제: 프로그램명 / 인용: "엑셀" / 수정 문장: "스프레드시트 프로그램의 피벗 테이블 기능으로 월별 매출을 요약한다."
- "○○전자 AB-123 모델처럼 온도 조절이 되는 오븐을 쓴다."  → 이름이 둘이라 두 건으로 지적
  → 문제: 상호 / 인용: "○○전자" / 수정 문장: "온도 조절이 되는 오븐을 쓴다."
  → 문제: 상품명 / 인용: "AB-123" / 수정 문장: "온도 조절이 되는 오븐을 쓴다."
지적하지 않음
- "스프레드시트 프로그램으로 표를 만든다."
- "산업안전보건법에 따라 보호구를 지급한다."
- "매슬로의 욕구 단계 이론에 따르면 …"
- "결과 파일은 PDF로 저장한다."
```
