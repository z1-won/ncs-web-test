# 06 수행 ② 재료·기기의 상표·상품·제조사명 (task `perform2_brands`)

보내는 것: 수행 내용 블록마다 '재료·자료'와 '기기(장비·공구)' 줄. 블록 제목은 참고(무슨 작업인지).
기준은 수행 내용 엔진의 LLM 규칙(`ncs_perform/rules/brands.py`)과 같다. 다만 LLM 검토 공통 형식(문단 번호 n, 인용, 수정 문장)으로 답하게 했다.
본문 문단의 상호·상품명은 기타 ③(`misc3_names`)이 따로 본다.

## [체크 항목]

```
[체크 항목] 수행 내용 ②
'재료·자료'와 '기기(장비·공구)'에 특정 회사의 상표명·상품명·제조사명·모델명이 노출되지 않았는가?
```

## [판단 기준]

```
[판단 기준]
재료·자료와 기기(장비·공구) 줄 하나하나에서 특정 회사가 소유한 이름을 찾는다. 한 줄에 여러 개면 이름마다 따로 지적한다.
- 지적함:
  · 상표: 특정 회사의 브랜드 이름
  · 상품명: 특정 회사의 제품·서비스 이름(소프트웨어, 클라우드 서비스, 생성형 AI 서비스 포함)
  · 제조사명: 장비·기기를 만든 회사 이름
  · 모델명: 특정 제품의 모델명·제품 코드
- 지적하지 않음:
  · 일반 명사·보통 명칭과 그 영문 병기(노트북, 프린터, 계산기, 작업 지시서, 스프레드시트 프로그램)
  · 이 분야에서 통용되는 약어·문서명·보고서명·장비의 보통 명칭: {분야_공용명칭}
  · 공공 표준·법령·규격 이름, 일반화된 기술 용어(관계형 데이터베이스, 웹 브라우저, 디지털카메라, 인터넷)
  · 오탈자·띄어쓰기·표기 오류(이 검사의 대상이 아님)
- 영문이라는 이유만으로 지적하지 않는다. 지적하는 이름은 "어느 회사의 무엇"인지 말할 수 있어야 한다. 확신할 수 없으면 지적하지 않는다.
```

`{문제_종류}` = `상표` | `상품명` | `제조사명` | `모델명`

"인용"은 이름 부분만, "수정 문장"은 그 이름을 일반 명칭으로 바꾼 줄 전체.

## [찾을 곳] — 슬라이스 ①·②(원고를 통째로·고정 길이로 보낼 때)만 붙임. ③은 코드가 이미 그 부분만 잘라 보냄

```
[찾을 곳]
각 학습 내용의 '수행 내용' 안에서 '재료·자료'와 '기기(장비·공구)' 제목 아래 줄만 검수 대상이다.
같은 수행 내용의 제목과 수행 순서는 무슨 작업인지 알기 위한 문맥으로만 쓴다.
```

## [예시] — 기본 예시(직접 만든 문장, 조정용·측정용 원고 문장은 쓰지 않음)

```
[예시]
지적함
- (기기) "• 노트북(갤럭시북 3), 레이저 프린터"
  → 문제: 상품명 / 인용: "갤럭시북 3" / 수정 문장: "• 노트북, 레이저 프린터"
- (재료) "• 3M 마스킹 테이프, A4 용지"
  → 문제: 제조사명 / 인용: "3M" / 수정 문장: "• 마스킹 테이프, A4 용지"
- (기기) "• 디지털 멀티미터(FLUKE 117)"
  → 문제: 모델명 / 인용: "FLUKE 117" / 수정 문장: "• 디지털 멀티미터"
- (기기) "• 협업 도구: 슬랙, 노션"
  → 문제: 상품명 / 인용: "슬랙" / 수정 문장: "• 협업 도구: 메신저, 문서 협업 프로그램"
지적하지 않음
- "• 전산 장비: 인터넷, 컴퓨터, 프린터, 복사기, 빔 프로젝터 등"
- "• 지원 도구: 통계 분석 도구, 문서 작성 도구, 화이트보드"
- "• 요구사항 정의서, WBS, 간트 차트"   (분야의 보통 명칭·약어)
- "• KS 규격집, 산업안전보건법 해설서"   (표준·법령)
```
