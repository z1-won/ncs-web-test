# 03 평가 ④ 평가 항목 (task `eval4_items`)

보내는 것: 학습 내용(N-M)마다 **평가 준거의 학습 목표**(참고)와 **평가 방법의 평가 항목**(검수 대상).
종결 어미(~여부·~능력·~수준·~정도)와 "학습 목표와 거의 같은 글자" 판정은 엔진(`ncs_evaluation/rules/items.py`)이 함 → LLM은 **내용**만 봄.

## [체크 항목]

```
[체크 항목] 평가 ④
'평가 방법'의 평가 항목에서 학습 목표와 연관성 있는 구체적인 내용을 개조식(명사형)으로 작성하였는가?
- 평가 항목 내용과 학습 목표가 유사하면 안 됨.
- 평가 항목 내용은 학습 목표에 기반해 구체적 내용을 서술하되, ~ 여부, ~ 능력, ~ 수준, ~ 정도 등으로 종결함.
```

## [판단 기준]

```
[판단 기준]
"검수 대상"의 평가 항목 하나하나를 같은 학습 내용의 "학습_목표"들과 견주어 본다. 학습_목표는 참고용이며 지적하지 않는다.
종결 어미(~여부, ~능력 등)는 이번 판단에 넣지 않는다.
- 지적하지 않음: 평가 항목이 학습 목표 가운데 하나에 기반하고, 그 목표를 이루었는지 확인할 수 있는 구체적인 지식·기술·결과물을 가리킨다.
- 지적함:
  · 목표와 무관: 어느 학습 목표와도 연결되지 않는다.
  · 목표 반복: 학습 목표 문장을 거의 그대로 옮기고 끝만 명사형으로 바꿨다. 구체화한 내용이 없다.
    (예: 목표 "고객 요구를 분석할 수 있다." → 항목 "고객 요구 분석 능력")
  · 막연함: 무엇을 아는지·하는지 대상이 없다. (예: 이해 여부, 기본 지식 정도, 실무 능력)
- 학습 목표 하나를 여러 평가 항목으로 나눈 것은 정상이다. 학습 목표마다 평가 항목이 다 있는지는 이번 판단에 넣지 않는다.
- 목표 반복과 정상의 경계: 목표의 낱말을 일부 그대로 써도, 목표보다 좁고 확인할 수 있는 대상(결과물, 기준, 절차의 한 단계)을 가리키면 정상이다.
  목표의 동사만 명사형으로 바꾸고 대상이 목표와 같으면 목표 반복이다.
  (목표 "요구 사항을 분석할 수 있다." → "요구 사항 분석 능력"은 목표 반복, "요구 사항을 기능·비기능으로 분류한 정도"는 정상)
- 한 평가 항목 문단에 여러 항목이 쉼표로 이어져 있으면 항목마다 따로 판단하고, 문제가 있는 항목만 인용한다.
- 평가 방법(서술형, 포트폴리오 등)이 무엇인지는 판단에 넣지 않는다.
```

`{문제_종류}` = `목표와 무관` | `목표 반복` | `막연함`

"수정 문장"은 평가 항목 한 줄. 종결은 원래 항목의 명사형 끝(~여부 등)을 그대로 둔다.

## [찾을 곳] — 슬라이스 ①·②(원고를 통째로·고정 길이로 보낼 때)만 붙임. ③은 코드가 이미 그 부분만 잘라 보냄

```
[찾을 곳]
각 학습의 '평가' 부분, '평가 방법' 표 안의 '평가 항목' 문단만 검수 대상이다.
'평가 준거' 표의 학습 목표(같은 학습 내용 N-M)는 견주어 볼 참고용이며 지적하지 않는다.
```

## [예시] — 기본 예시(직접 만든 문장)

```
[예시]
학습 목표: "고객의 요구 사항을 수집하여 우선순위를 정할 수 있다."
지적함
- "고객 요구 사항 수집 및 우선순위 결정 능력"
  → 문제: 목표 반복 / 수정 문장: "인터뷰·설문 결과를 요구 사항 목록으로 정리하는 능력"
- "관련 내용 이해 여부"
  → 문제: 막연함 / 수정 문장: "중요도·긴급도 기준에 따라 요구 사항 우선순위를 매기는 능력"
- "문서 편집 프로그램 활용 능력"
  → 문제: 목표와 무관 / 수정 문장: "수집한 요구 사항을 기능·비기능으로 분류한 정도"
지적하지 않음
- "인터뷰·설문 결과를 요구 사항 목록으로 정리하는 능력"
- "중요도·긴급도 기준에 따라 요구 사항 우선순위를 매기는 능력"
```
